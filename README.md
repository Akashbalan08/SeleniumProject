## Overview
This project involves the automation of end to end flow of a demo website, wherein we use Selenium(java), the automation process covers the whole flow starting from logging in and ending with log-out

### Tested Features
- Login feature
- Add to Cart feature(multiple products)
- Checkout
- Additional information
- Order Confirmation
- Logout feature

### Deliverables
- Automated Test scripts

### Tools Used
- Selenium WebDriver
- Java
- Eclipse IDE
